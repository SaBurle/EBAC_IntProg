## Como o repositório está organizado

Cada módulo (`Mx - Nome`) tem estas pastas:

- **Aulas:** código feito acompanhando as aulas.
- **Exercícios:** resolução dos exercícios do módulo.
- **Erros - Dúvidas - Tentativas:** versões intermediárias, com erros e correções. Mostram o processo de depuração.
- **Back Up:** cópias de segurança das versões.
- **Material Complementar:** conteúdo fornecido pelo curso (apostilas, soluções de referência).
- **Fluxogramas:** diagramas em draw.io (quando o módulo tem).

Arquivos com **"Prof"** ou **"(professor)"** no nome são referências do professor, não trabalho meu.
